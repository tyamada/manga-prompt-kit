# 汎用プロンプト集

このフォルダーの9本は制作記録をもとに**新しく編集したテンプレート**です。過去にそのまま使用した文面ではありません。角括弧の項目を自分の作品に置き換え、必要な画像や脚本を添付して使います。

| 順番 | プロンプト | 必要な入力 | 出力 |
|---|---|---|---|
| 1 | [人物と作品の設計](01-character.md) | 題材、人物数、舞台 | 設定表と識別方法 |
| 2 | [表情とギャグ表現](02-expression.md) | 承認済み設定画、性格 | 表情の提案と設定画像 |
| 3 | [4コマ脚本とコマ割り](03-script.md) | 設定、題材 | セリフと画面設計 |
| 4 | [カラー4コマ作画](04-color-art.md) | 設定画、確定脚本、背景 | 確認用の4コマ原稿 |
| 5 | [部分修正](05-local-edit.md) | 最新原稿、修正箇所 | 修正版と変更記録 |
| 6 | [縦書きと吹き出し](06-lettering.md) | 原稿、脚本、文字環境 | 文字組みと読み順 |
| 7 | [線と彩色の回復](07-color-repair.md) | 正しい構図、正常な色参照 | 構図を維持する色修正版 |
| 8 | [冊子と多言語PDF](08-pdf-translation.md) | 文字なし作画、対訳 | PDF制作計画（本テンプレートは計画段階） |
| 9 | [最終確認と引き渡し](09-review.md) | 採用画像、脚本、記録 | 投稿用一覧と確認結果 |

まず1本の4コマで流れを確かめます。提案・試作・採用・公開は別の状態です。「提案だけ」と頼んだ段階では作画を進めず、作画後も採用や外部への投稿を自動的に行わないよう依頼文で範囲を示します。

各実例の `prompts/` に置くテキストは、保存されていた**画像生成・編集ツール向けの実使用文**です。チャットへ人が送った短い依頼とは区別します。英語の原文を保っているものがあります。

『ためし部』の背景・家具には[採用部室v2の設定](../series/tameshibu/clubroom-20261121/README.md)と[原稿用の部室参照指示](../series/tameshibu/clubroom-20261121/production-prompt.md)を併用します。実使用の背景修正指示4本は設定資料内に分け、汎用テンプレート9本とは区別しています。未公開背景画像本体は含めていません。
