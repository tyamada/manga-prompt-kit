# 最終確認と引き渡し

制作記録をもとに編集した汎用テンプレートです。

## 入力

採用候補画像、確定脚本、設定画、採用記録。

## コピー用プロンプト

```text
添付の[作品名]の採用候補を確認し、外部投稿前の一式をまとめてください。
各原稿について、全コマのセリフ、話者、縦書き、発言順、人物識別、手指、小物の数と向き、線と塗り、背景、権利表示を照合します。
スマートフォン幅と拡大表示の両方で確認し、実施できなかった確認は区別してください。
投稿用は[例：sRGB JPEG、長辺2400px以内]とし、元画像と縦横比を保ちます。
編集用PNG、脚本、使用プロンプト、必要な参照画像、追加修正、採用日を対応付けて保存してください。
旧版は残し、採用一覧にタイトル、版、寸法、画像ファイル、チェックサムを記録します。
発行日・改訂日・実際の投稿日を区別し、予約や投稿の完了を画像の完成だけから推定しないでください。
外部サイトへのアップロードは行わず、確認用一覧と配布候補ZIPを作成してください。
```

## 確認すること

一覧とZIPの画像が同じ版か。採用画像が履歴の途中に取り残されていないか。

## Releaseの公開候補をまとめる場合

```text
アプリ用PDFとpixiv用画像を、それぞれ別のGitHub Releaseの公開予定データとしてまとめてください。
公開先はこの制作資料リポジトリです。既存のアプリ側2配布先は将来廃止予定で、移行完了までは維持します。
ファイル名、作品、版、寸法またはページ数、バイト数、SHA-256、CC BY 4.0の表示を一覧へ記録します。
PDFは既存サンプルIDと旧2配布先のファイル名から新しいファイルへの対応表を残します。
未確定の公開URLを作らず、公開状態は「公開予定」とします。
今回はアップロード、Release作成、旧URL削除、アプリ更新は行いません。
```
