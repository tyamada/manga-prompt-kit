# 4コマ脚本とコマ割り

制作記録をもとに編集した汎用テンプレートです。

## 入力

人物設定、採用版を明示した舞台・家具設定、題材。既存作品なら最新脚本と前後の状態。

## コピー用プロンプト

```text
[作品名]の4コマ1本の脚本案を[案数]案作ってください。今回は脚本とコマ割り案までです。
人物設定：[添付設定]
時期と場所：[作中時期、場所]
舞台基準：[採用設定の版、部屋の寸法・壁面・家具配置]
開始時の状態：[机の開閉、座席、小物、前の原稿から引き継ぐ状態]
題材：[困り事、小さな発見]
読後感：[目標]

各案を、コマ番号、登場人物、行動、カメラの位置と向き・寄り引き、セリフ、話者、発言順、必要な小物、家具の開閉状態の表にしてください。
カメラを移したときの画面上の左右と、家具・小物の前後の連続性を確認してください。脚本と採用した部屋の固定配置が両立しない場合は、作画前に相談点として示してください。
最初に場所を見せる必要があるコマ、表情中心のコマ、手元や全身で関係を伝えるコマを選び分けてください。
各コマのセリフは少なくし、長い説明を表情や行動へ置き換えられるか検討してください。
オチに必要な物は前のコマで自然に準備し、持ち物・席順・光の連続性を保ってください。
物語の季節を投稿月に合わせて変更しないでください。
画像生成と採用の判断は、脚本を選んだ後に行います。
```

## 確認すること

セリフを読まなくても動作が分かるか。話者と発言順が指定されているか。4コマ目だけに突然小物が現れないか。

『ためし部』は[部室v2](../series/tameshibu/clubroom-20261121/README.md)の寸法・壁面を舞台基準にします。延長板の開閉・人数・小物・窓外の季節は脚本で指定し、背景画の状態を全コマへ流用しません。
