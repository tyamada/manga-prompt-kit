# 部分修正

制作記録をもとに編集した汎用テンプレートです。

## 入力

修正対象の最新版、正常な設定画、正しい脚本。

## コピー用プロンプト

```text
添付1の原稿の[上から何コマ目]を修正してください。
変更対象：[人物、背景、小物、吹き出し、文字]
現在の問題：[画面上でどこがどう不自然か]
変更後：[位置、方向、数、表情などを具体的に]
維持する要素：[セリフ全文、顔、ポーズ、他コマ、枠、寸法]
添付2は[顔／色／小物]だけの参照で、構図は添付1を基準にします。
左右は[本人から見た左右／読者から見た左右]で示します。
全体を鏡像反転せず、指定箇所だけを編集してください。
修正画像は別版で保存し、対象箇所と全4コマの両方を確認してください。
変更結果、他に変化した箇所、確認できていない点を報告してください。
```

## 確認すること

指定箇所以外の字や色が変わっていないか。維持の指示を守れたという説明だけで判断せず画像を比較する。

## 部室背景を直す場合

『ためし部』は[採用部室v2](../series/tameshibu/clubroom-20261121/README.md)を基準に、カメラ・壁面・机の開閉状態と修正範囲を指定します。人物・セリフ・別コマを維持し、採用設定の変更と既存原稿への修正を別の指示として扱います。
