制作記録では11月9日改訂案v8を参照し、1コマ目の放射背景と大きなセリフを継承、2コマ目で部室・廊下の境界と踏み出す足、3コマ目で立ち止まるくるみの全身、4コマ目で地図と赤丸の寄りを描いています。承認済み全4セリフ、赤丸とペン先、疑問符、移動矢印の見え方を照合した記録があります。全身・足元と2・3コマ目のカメラ方向の切り替わりは再利用時にも確認します。旧参照画像そのものは本例へ追加していません。
