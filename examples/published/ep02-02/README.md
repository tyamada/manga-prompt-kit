## 制作と背景整理

[実使用プロンプト](prompts/背景整理_実使用プロンプト.txt)は採用版の制作プロンプトJSONから第2回のprompt値だけを原文抽出しています。既存の2×2中間画稿を編集し、右上→左上→右下→左下の4コマを、最終ページで上から順に配置しました。中間画稿・他の回の原文は収録していません。

1コマ目は低い視点の部室・机・床を残し、しゃがんだ高さを示します。2コマ目はこよみ・机の脚・床を残して遠景の棚と窓を省略。3コマ目は机の下の床・紙の家・必要な脚を残し、4コマ目はくるみの背後を黄色からクリームの抽象背景に整理し、家と床の位置関係を維持しています。

セリフ4発言は承認済みの内容を生成指示に明記しています。制作担当による生成原本・最終ページの目視確認記録と、こちらでの採用JPEGの寸法・RGB/ICC・SHA-256照合を区別します。
