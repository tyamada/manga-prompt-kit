## 構図と確認の記録

1コマ目は廊下・窓外の遠景と2人の立ち位置、2コマ目は空色の抽象背景とくるみの寄り、3コマ目は2人が視線を下げる全身寄り、4コマ目は足元の傘立てとピンクのリボンを強調しています。

制作記録では東京スカイツリーの表記、黄色の左腕時計、青白縞の傘とピンクのリボンを確認しています。傘立てを1・3コマ目にも控えめに描き、同じ廊下の近くにあったことを示す構成が確認点です。
