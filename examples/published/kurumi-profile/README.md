# 三輪くるみ キャラクター紹介

[pixiv公開作品](https://www.pixiv.net/artworks/151939759)。採用版はv1（採用日2026-11-09）です。

[実使用プロンプト](prompts/production-v1.json)は制作記録の「プロンプト」配列をそのまま抜き出したものです。立ち絵と表情を生成・修正し、人物情報と6表情のラベルを別工程で組版しています。紹介画像全体を一度に生成する指示ではありません。元の制作記録に残る「未採用」「投稿日時未定」は途中時点の状態で、採用最新版と今回の投稿完了報告を優先します。

参照画像の対応は指示内の人物・服装・髪型の条件と照合してください。元の作業用パスや参照画像そのものは本例に同梱していません。[人物紹介の詳細な工程](../../01-character/README.md)も参照してください。

公開根拠はユーザーの投稿完了報告とURLです。サイト制限によりpixivページ本体は直接確認していません。[公開記録と完成画像の配布先](../../../releases/pixiv-publication-status.md)。
