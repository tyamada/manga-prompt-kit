## 制作と背景整理

[実使用プロンプト](prompts/背景整理_実使用プロンプト.txt)は採用版JSONの第8回から原文抽出しました。2×2中間画稿を右上→左上→右下→左下の順に読み、最終ページで上から4コマに並べます。

1コマ目はカートでの配達が伝わるよう部室と机を残します。2コマ目は車輪と天板の継ぎ目の接触を残し、遠景を淡いコーラルとクリームで整理します。3コマ目はすみれが消しゴムを渡す手元を淡いラベンダーとクリームで示し、4コマ目はくるみの反応を暖かな黄色とクリームで示します。木製のカート、白旗、時刻表の意匠と既存のセリフを維持する指示です。
