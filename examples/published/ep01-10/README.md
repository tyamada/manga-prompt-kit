## 構図と確認の記録

1コマ目は曲がり角と片膝をつくすみれを広く描き、2コマ目は床へ矢印を置くくるみの全身と床との接点、3コマ目はこよみの手・足の動作線、4コマ目は部室に向かう矢印と凪の静かな反応を描いています。

制作記録では、床の矢印が平置きで奥の部室入口へ向かうことと、くるみの黄色い時計を確認しています。すみれの新たな姿勢と足元は再利用時にも確認する対象です。
