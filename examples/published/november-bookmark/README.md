# 11月季節イラスト「秋をひとつ、持ち帰ろう。」

[pixiv公開作品](https://www.pixiv.net/artworks/152042238)。2026年11月14日採用の文字入りv1、投稿用JPEGは1024×1536pxです。

## 制作手順

1. こよみ・凪・くるみ・すみれの順に4人の採用人物紹介を参照画像として渡します。人物紹介のレイアウトや文字は転写せず、顔・髪型・制服・体格の基準にします。[人物紹介の制作例](../../01-character/README.md)。
2. [文字なし作画の実使用プロンプト](prompts/prompts.json)で、落ち葉のしおり作りを楽しむ4人を描きます。人物はセル塗り、背景は淡く、手・視線・持ち物とタブレットのカメラ／消灯LEDの配置を確認します。
3. 採用した文字なしイラストを編集入力とし、[文字追加の実使用プロンプト](prompts/prompts_lettering_v1.json)で見出し、作品名、作者名、CC BY 4.0の表示を加えます。人物や構図を保持し、追加した日本語と顔への重なりを目視確認します。この実例は画像編集による文字追加であり、別組版を使う[汎用の文字制作手順](../../../docs/lettering.md)とは方法が異なります。
4. 採用した文字入りv1を投稿用JPEGへ反映します。指示だけで同じ画像が再現されることは保証しません。

JSONから11月の指示だけを原文のまま抜き出しています。参照人物の完成画像は[人物紹介Release](https://github.com/tyamada/manga-prompt-kit/releases/tag/pixiv-tameshibu-characters-20261109-v1)で配布しています。
