# 部室背景v2を参照する原稿制作指示

2026年11月21日の採用設定から新しく編集したコピー用テンプレートです。実使用原文は[設定資料](README.md)に分けています。採用背景画像はこのリポジトリに収録していないため、使用者が正本を用意し、設定JSONのSHA-256と照合して添付してください。

```text
『ためし部』の[話・回・タイトル]を、確定脚本に沿って確認用に制作してください。
添付1：採用済み人物・衣装設定。
添付2：寸法反映修正版v2の4方向のうち[方向番号・カメラ位置と向き]。部屋の配置・意匠の参照。
添付3：[改訂対象がある場合のみ、現在の構図基準となる最新版]。
設定文書：部室寸法・配置の正本。添付画像と見かけが異なる場合も寸法は設定値を優先し、矛盾は作画前に示す。
固定壁面と寸法、脚本上の状態、人物設定の役割を分ける。構図基準と両立しない場合は制作前に変更範囲を確認する。
確定脚本：[話者・セリフ・動作・カメラ・机の開閉・小物を指定]。

室内は仕上げ壁内寸4500mm（窓〜廊下）×3600mm（本棚壁〜対面壁）、天井2700mm。
方位は配置管理用。北壁に幅2400×奥行350×高さ2000mmの二連本棚と東寄りの掲示板、西壁に窓、東壁に出入口、南壁は無地。
出入口有効1000×2100mm、窓台900mm・窓上端2400mm。幅や枠の未確定部分を新しい固定設定にしない。
机本体1200×600×高さ700mm。各短辺に300×600mmの延長板。長辺は本棚壁に平行、短辺は窓・廊下側へ向ける。
机は収納時1200、片側展開1500、両側展開1800mm。今回の開閉状態は[脚本の指定]。参照画の両側展開を無条件で流用しない。
青い折りたたみ椅子は基本4脚、長辺両側に2脚ずつ。幅440・奥行505・座面高425・背上端740mm、座席中心間隔600mmを基準にする。
人物・家具・壁を同じ床と透視投影で描く。人物を大きく見せるために家具実寸を変えず、必要なら机や背景を画面外へ切る。
カメラの移動に伴う読者視点の左右を確認する。壁面関係は変えず、全体の鏡像反転をしない。
窓外と光は[作中の季節・時刻・天候]に合わせる。桜・昼光・カメラ高1500mmは全原稿の固定条件ではない。
位置や距離を説明するコマでは必要な背景・床・支えを残し、感情や会話中心のコマは意図的な抽象背景にできる。窓や棚の断片を中途半端に残さない。
人物は明瞭な一重線とセル塗り、背景は細く薄い線と少し絵画寄りの塗り、人工物はセルルックを保つ。
4方向の採用画像は意匠・配置参照で厳密な寸法図ではない。mm設定と脚本の連続性を確認する。
出力形式・コマ組版・文字の扱いは今回の承認仕様に従う。表紙に本編4コマの枠を適用しない。
今回は確認用の別版を保存する。既存採用稿の置換・外部投稿は別の明示指示があるまで行わない。
```

確認時はカメラ方向、窓・本棚・掲示板・出入口の壁面、机の長短辺・展開状態、同一床面の縮尺、脚本の連続性を比較します。画面上で確認できない部分や参照画像の不足は、そのまま未確認として残します。

正本を添付できない場合は「添付2」を削除し、「設定文書による配置案。採用画像の見た目は未確認」と明記します。旧稿の部分修正に使う際は、依頼外の背景をv2へ置き換えません。私用の参照画像と外部公開候補は別に管理します。
