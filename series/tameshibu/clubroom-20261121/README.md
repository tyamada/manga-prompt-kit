# ためし部の部室設定・寸法反映修正版v2

2026年11月21日、ユーザーが4方向背景v2を採用しました。今後の制作はこの配置・寸法を使います。初版は制作元で履歴として保持します。[機械可読設定](settings.json)には寸法、平面座標、参照画像の識別名・SHA-256と公開状態を収録しています。

設定文書と制作プロンプトだけを公開しています。背景画像4枚はpixiv未公開で、このリポジトリ・Releaseに収録していません。採用済みを公開済みとは扱いません。画像を参照する作業では、利用者が保管する採用v2の正本を、識別名とSHA-256で照合して使用します。公開ダウンロードURLはありません。

## 基準寸法

単位は特記しない限りmm。室内寸法は仕上げ壁の内側から内側です。

| 対象 | 採用寸法 |
|---|---|
| 窓側〜廊下側 | 4,500 |
| 本棚壁〜対面壁 | 3,600 |
| 床面積／天井高 | 16.2㎡／2,700 |
| 本棚2台合計 | 幅2,400×奥行350×高さ2,000（幅1,200を2台） |
| 出入口の有効開口 | 幅1,000×高さ2,100、上部に欄間 |
| 窓台／窓上端 | 床から900／2,400 |
| 机本体 | 幅1,200×奥行600×高さ700 |
| 短辺の延長板 | 各300×600、2枚 |
| 机の全長 | 収納時1,200、片側展開1,500、両側展開1,800 |
| 椅子4脚 | 幅440×奥行505、座面高425、背上端740 |
| 座席中心間隔 | 600、長辺の両側に2脚ずつ |

机の長辺は本棚壁に平行、短辺は窓側・廊下側へ向けます。部屋に対して斜めに置きません。机・椅子と人物は同じ床面・透視投影で扱い、人物を大きく見せるために家具の実寸を変えません。人物の大きさと見せたい動作を先に決め、画面外へ切れる机・背景は必要な部分だけ描きます。

## 壁面と4方向

北・西などの方位は配置管理の仮称で、地理上の方角は未設定です。北壁に木製二連本棚と、その東寄りにコルク掲示板、西壁に連続窓とクリーム色カーテン、東壁に廊下側の出入口、南壁は淡いクリーム色の無地壁です。床は木、天井は白いパネルと長方形照明です。

| 参照識別名（画像未収録） | カメラ | 保持する壁面関係 |
|---|---|---|
| 01_窓を左に本棚側.png | 南側→北の本棚壁 | 左に窓、正面に本棚と掲示板、右側壁に出入口 |
| 02_窓に向かって.png | 東の廊下側→西の窓 | 正面に窓、右側壁に本棚、左側壁は無地 |
| 03_窓を背に廊下側.png | 西の窓側→東の廊下 | 正面に出入口、左側壁に本棚と掲示板、右側壁は無地 |
| 04_窓を右に壁側.png | 北の本棚側→南の無地壁 | 右側壁に窓、左側壁に出入口。本棚と掲示板はカメラの背後 |

反対向きへカメラを移しても、窓・本棚・掲示板・出入口の壁面を入れ替えたり、画像全体を鏡像反転したりしません。カメラの背後や画面外の家具を無理に見せません。

## 平面座標と余白

南西の室内隅を原点とし、xは廊下側、yは本棚側へ増加します。室内範囲は(0,0)〜(4500,3600)、本棚は(600,3250)〜(3000,3600)、机中心は(2250,1645)。机本体は(1650,1345)〜(2850,1945)、両側展開時は(1350,1345)〜(3150,1945)です。

両側展開時の机短辺から窓壁・廊下壁は各1,350、北側椅子外形から本棚前面は800、南側椅子外形から壁は840を作画目安とします。椅子を引く・座る動作で余白は変わります。出入口枠・窓の幅や割り付けの詳細は未確定です。

## 原稿へ適用する優先順位

1. カメラの位置・向きを決め、対応する採用v2を選びます。寸法は設定値を基準とし、画像の見かけから変更しません。
2. 背景画は両側延長板を開いた全長1,800の参照状態です。原稿では確定脚本の開閉状態と前後の連続性を優先します。人数・椅子や小物の数も場面に従います。
3. 窓外の季節・時刻・天候・光は作中時期と脚本に合わせます。参照画像の桜や昼光は全場面へ固定しません。
4. 位置・高さ・距離の説明が必要なコマは必要な床・机・背景を残し、会話中心のコマは抽象背景を選べます。背景の断片や浮いた家具を残しません。
5. 細く薄い線と少し絵画寄りのアニメ背景塗り、人工物のセルルックを維持します。既存の公開原稿や当時の実使用プロンプトは遡って書き換えません。

## 既存資料との整合と参照不足の扱い

新規制作は寸法・固定壁面を本設定、机の開閉・小物・人数・窓外を確定脚本、人物・衣装を各採用正本へ分けます。構図基準と矛盾する場合は先に変更範囲を確認します。旧稿の文字・彩色だけを直す依頼では、依頼外の背景をv2へ改稿しません。歴史資料の右・左・季節の指定は当該原稿の制作時条件です。

settings.jsonの家具作画補助寸法は作画の暫定値で、脚・幕板・金具などの製作設計の確定を意味しません。机中心・座席間隔・余白は同じ平面座標系で使い、画角ごとの見た目から値を変えません。

画像を入手できない場合は、文書で寸法・壁面・カメラを確認できても画像の見た目は未確認です。「添付」は正本を実際に選んで渡す場合だけ使います。背景を新規に試作しても採用v2と同一とは扱いません。作業用参照と公開候補を分け、未公開画像をレビュー・プレビュー・ZIP経由でも公開しません。
