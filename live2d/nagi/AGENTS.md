# 瀬尾凪 Live2Dの作業ルール

このルールは `live2d/nagi/` の制作・更新に適用する。

1. 変更したモデル、素材、モーション、検証記録を確認し、配布するファイルを `live2d/nagi/` 以下の該当フォルダーに保存する。版比較に必要な既存の試作は保持する。
2. 配布モデルは単体WAVなしで再生できるようにし、音声付きプレビューを公開する場合は音声クレジットと適用規約を明記する。ローカルパスなど制作環境固有の情報を公開資料に残さない。
3. 公開成果物や再生手順が変わったら、凪のREADME、リポジトリのREADME、`docs/` 以下のGitHub Pagesの該当箇所を更新する。
4. モデルの参照先、再生結果、リンク、ライセンス表記、差分を確認する。配布ファイルを更新したら `verification/windows-draft-SHA256SUMS` も更新する。
5. 一まとまりの作業が完了するたびに、その作業の変更だけをコミットし、コミットIDと検証結果を報告する。
6. 作業中に新しく開いたエクスプローラーのウィンドウは、作業終了時に閉じる。
