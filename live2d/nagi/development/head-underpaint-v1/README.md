# 瀬尾凪の正面PSD補足作画 v1

[正面PSD](nagi-front-head-underpaint-v1.psd) · [Cubism Editor確認用CMO3](nagi-front-head-underpaint-v1.cmo3)

[透過の肌パーツ素材](../head-turn-art-v1/skin-parts-sheet.png)を既存の正面PSD（口リグ素材v5）の1024×1536 pxに合わせた。額、本人右耳、本人左耳、首の各レイヤーを分離し、正面原画の頬・耳・首から採った肌色に合わせた。PSDでは補足4枚を既存画の背面に配置した。

Cubism Editor 5.3.05で4枚の取り込みを確認し、CMO3で首を描画順488、左右の耳を489、額を490に設定した。既存画は500、閉口線は501。正面を拡大し、前髪、左右の耳、顎と襟の付近の重なりを確認した。PSDを新規モデルとして読み込む場合は同じ描画順を設定する。

今回のCMO3は重なり確認用。顔角度の変形キーと、既存の視線・まばたき・口パクとの組み合わせは次工程。
