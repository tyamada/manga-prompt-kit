# 瀬尾凪 正面原画の下地修正版 v5

[修正版PSD](nagi-new-front-underpaint-v5.psd) · [描画順調整済みCMO3](nagi-new-front-underpaint-v5.cmo3) · [下地修正版 v4](../nagi-new-front-underpaint-v4/)

口を隠すと見える肌の色を、口の上下と左右の肌色に合わせました。全表示のPSD合成はv4と画素単位で一致します。

Cubism Editor 5.3.05で、前髪と口の表示・非表示を4通り切り替え、口を隠した部分の肌色が周囲となじみ、透明な穴が出ないことを確認しました。CMO3は前髪を表示した状態で保存しました。描画順は後ろ髪450、額・こめかみの下地470、目・口の下地480、前髪520、その他500です。
