# 瀬尾凪 顔角度XYZ試作 v1

[編集用CMO3](nagi-angle-xyz-v1.cmo3) · [Viewer用モデル](runtime/) · [音声合成クエリ](narration-v2-accent-preview-3-query.json)

視線v2を基に、額・左右の耳・首の補足作画と、髪や頬の分割境界を補う下地を追加した。角度X・Yには小さな平面移動で左右・上下・斜めを確認するキー、角度Zには首元を軸とする最大約4度の傾きを設定した。胴・腕・脚は顔のデフォーマの外に置いた。

Cubism Viewer 5.3.05で `runtime/nagi-angle-xyz-v1.model3.json` を開き、`AngleNarration` を選ぶと約13秒の比較モーションを再生できる。音声を付ける場合は、同梱のクエリをVOICEVOX:波音リツ（ノーマル、スタイル9）で合成し、WAVをViewerの音声欄に指定する。音声利用時は「VOICEVOX:波音リツ」を表示する。[波音リツの利用規約](https://www.canon-voice.com/terms/)

音声を割り当てた通し再生で、前髪・耳・首と、視線・まばたき・口パクの組み合わせを目視確認した。更新した下地で頬と耳付近の大きな抜けを覆った。拡大時には髪・耳・顎に継ぎ目や二重の輪郭が残る。左右斜めの参考画に合わせた輪郭変形と奥側の目の縮みは今後の作業。
