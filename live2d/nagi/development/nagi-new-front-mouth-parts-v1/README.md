# 瀬尾凪 正面原画の口パク用パーツ分け v1

[修正版PSD](nagi-new-front-mouth-parts-v1.psd) · [描画順調整済みCMO3](nagi-new-front-mouth-parts-v1.cmo3) · [下地修正版 v5](../nagi-new-front-underpaint-v5/)

下地修正版 v5 を基に、閉口線（Mouth_Closed_Line）、開口輪郭（Mouth_Open_Outline）、口内（Mouth_Interior）、舌（Mouth_Tongue）を独立したレイヤーにしました。閉じ口のPSD合成はv5と画素単位で一致します。

Cubism Editor 5.3.05で、閉じ口、開き口の3パーツを重ねた状態、舌を隠した口内、開口輪郭単独を確認しました。CMO3は閉じ口で保存しています。開き口を見るには閉口線を隠し、口内、舌、開口輪郭を表示してください。描画順は口内510、舌511、開口輪郭512です。口の開閉・口幅の変形キーは次工程です。
