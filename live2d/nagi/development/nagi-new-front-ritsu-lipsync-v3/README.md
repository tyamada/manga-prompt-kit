# 瀬尾凪 新規正面モデルの波音リツ口パク v3

[Viewer用モデル](runtime/nagi-new-front-ritsu-lipsync-v3.model3.json) · [口パクモーション](runtime/nagi-new-front-ritsu-lipsync-v3.motion3.json) · [編集元の口リグ v2](../nagi-new-front-mouth-rig-v2/)

[口パク v2](../nagi-new-front-ritsu-lipsync-v2/)を基に、マ行・バ行の10箇所で閉口前後の開きと口幅の補間を調整しました。閉口中の横幅を標準に寄せ、周囲の母音からの切り替えを整えました。静かな促音3箇所では開きを小さく保ち、前後のつながりを調整しました。[区間・開閉・口幅の比較表](consonant-timing.csv)音声とモーションの長さは約13.003秒です。[全フレーズ確認版と発音境界](../front-separation/nagi-narration-v2-accent-v3-full-sync/)

Cubism Viewer 5.3.05でモデルを開き、motions → Narration のモーションを選択して再生します。音声を合わせる場合は、モーションにローカルのアクセント試聴版3のWAVを指定してください。音声を割り当てた状態で再生し、再生中の口形と終端の閉口を目視確認しました。口形は既存の推定発音境界を基に調整しました。発音ごとの聴き合わせは未実施です。v2の休止中の閉口と標準幅は維持しています。

確認に使用した音声は **VOICEVOX:波音リツ** です。[波音リツの音声利用規約](https://voicevox.hiroshiba.jp/product/namine_ritsu/) · [モデル素材の利用条件](../../LICENSE.md)
