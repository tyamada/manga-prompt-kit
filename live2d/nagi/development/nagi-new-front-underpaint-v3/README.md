# 瀬尾凪 正面原画の下地修正版 v3

[修正版PSD](nagi-new-front-underpaint-v3.psd) · [描画順調整済みCMO3](nagi-new-front-underpaint-v3.cmo3) · [下地追加版 v2](../nagi-new-front-underpaint-v2/)

前髪を隠した際に額とこめかみに残る線を前髪側へ移し、額からこめかみまで肌色がつながるように下地を描き直しました。前髪の下に出る眉の線も描き直しています。全表示時のPSD合成は下地追加版 v2 と画素単位で一致します。

Cubism Editor 5.3.05で、前髪の表示と非表示を切り替え、正面の合成と額・こめかみの肌を確認しました。目の周囲には目レイヤーの肌色が一部残ります。CMO3は前髪を表示した状態で保存しました。描画順は後ろ髪450、額・こめかみの下地470、目・口の下地480、前髪520、その他500です。
