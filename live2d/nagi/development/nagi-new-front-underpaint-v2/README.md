# 瀬尾凪 正面原画 v2 の下地追加版

[下地追加PSD](nagi-new-front-underpaint-v2.psd) · [描画順調整済みCMO3](nagi-new-front-underpaint-v2.cmo3) · [元の正面原画 v2](../nagi-new-front-v2/)

正面原画 v2 の10レイヤーに、額・こめかみ、右目、左目、口の肌を4レイヤー追加しました。すべて表示したPSDの合成は元の正面原画と画素単位で一致します。

Cubism Editor 5.3.05で、全表示の正面と、前髪・右目・左目・口を非表示にした状態を確認しました。前髪の下には額とこめかみ、目と口の開口部には肌が残り、対象の肌に透明な穴が出ないことを確認しました。前髪をすべて隠すと、元の分割境界に沿う細い線は一部見えます。

PSDから新規モデルを作ると、描画順が一律500になるため下地が前面に出る場合があります。同梱のCMO3は後ろ髪450、額・こめかみの下地470、目・口の下地480、その他500に設定しています。Cubismでの作業再開にはこのCMO3を開いてください。
