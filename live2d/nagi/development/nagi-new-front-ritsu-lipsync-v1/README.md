# 瀬尾凪 新規正面モデルの波音リツ口パク v1

[Viewer用モデル](runtime/nagi-new-front-ritsu-lipsync-v1.model3.json) · [口パクモーション](runtime/nagi-new-front-ritsu-lipsync-v1.motion3.json) · [編集元の口リグ v2](../nagi-new-front-mouth-rig-v2/)

口リグ v2 を2048 × 2048のテクスチャ1枚で書き出しました。既存のアクセント試聴版3の全フレーズ確認版から開閉と口幅のカーブを移し、発音時刻を保持しながら浅い開きと口幅を抑えました。音声とモーションの長さは約13.003秒です。[全フレーズ確認版と発音境界](../front-separation/nagi-narration-v2-accent-v3-full-sync/)

Cubism Viewer 5.3.05でモデルを開き、motions → Narration のモーションを選択して再生します。音声を合わせる場合は、モーションにローカルのアクセント試聴版3のWAVを指定してください。音声を割り当てた状態で再生し、再生中の口形と終端の閉口を目視確認しました。発音境界は全フレーズ確認版から引き継いでいます。

確認に使用した音声は **VOICEVOX:波音リツ** です。[波音リツの音声利用規約](https://voicevox.hiroshiba.jp/product/namine_ritsu/) · [モデル素材の利用条件](../../LICENSE.md)
