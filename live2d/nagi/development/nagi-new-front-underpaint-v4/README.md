# 瀬尾凪 正面原画の下地修正版 v4

[修正版PSD](nagi-new-front-underpaint-v4.psd) · [描画順調整済みCMO3](nagi-new-front-underpaint-v4.cmo3) · [下地修正版 v3](../nagi-new-front-underpaint-v3/)

左右の目レイヤーの肌色と、目を隠したときに見える下地の色を、額・こめかみから続く周囲の肌色に合わせました。まつ毛、白目、虹彩の形を保っています。

Cubism Editor 5.3.05で、全表示、前髪だけ非表示、前髪と片目を非表示にした左右それぞれの状態、前髪と両目を非表示にした状態を確認しました。CMO3は前髪を表示した状態で保存しました。描画順は後ろ髪450、額・こめかみの下地470、目・口の下地480、前髪520、その他500です。
