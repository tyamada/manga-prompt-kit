# 瀬尾凪 新規正面モデルの口リグ v2

[編集用CMO3](nagi-new-front-mouth-rig-v2.cmo3) · [口リグ v1](../nagi-new-front-mouth-rig-v1/)

開閉（ParamMouthOpenY）の0.5に中間キーを追加しました。口幅−1・0・1の各キーで、開き口の不透明度は開閉0・0.5・1に対して0%・100%・100%、閉口線は100%・0%・0%です。開口輪郭・口内・舌は同じワープデフォーマで変形します。開閉と口幅の初期値は0です。

Cubism Editor 5.3.05で、閉口から最大開口まで開閉と口幅を変え、輪郭・口内・舌の重なりを拡大して確認しました。閉口から半開きまでは不透明度が補間され、半開き以降は口内の色が保たれます。
