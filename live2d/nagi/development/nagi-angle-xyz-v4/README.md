# 瀬尾凪 顔角度XYZ v4

[編集用CMO3](nagi-angle-xyz-v4.cmo3) · [Viewer用モデル](runtime/) · [音声合成クエリ](narration-v2-accent-preview-3-query.json) · [顔角度XYZ v3](../nagi-angle-xyz-v3/)

角度Xの左右端で後ろ髪の上端とその下の頂点を調整し、外縁の折れをなだらかにした。左右の耳の下地に不透明度キーを追加し、顔を振ったときに奥側の下地だけが薄くなるよう調整した。

Cubism Viewer 5.3.05で `runtime/nagi-angle-xyz-v4.model3.json` を開き、`AngleNarration` を再生する。音声を付ける場合は、同梱のクエリをVOICEVOX:波音リツ（ノーマル、スタイル9）で合成し、WAVをViewerの音声欄に指定する。音声利用時は「VOICEVOX:波音リツ」を表示する。[波音リツの利用規約](https://www.canon-voice.com/terms/)

音声を割り当てた通し再生で、左右端と斜め向き、視線・まばたき・口パクを目視確認した。髪の外縁の折れと奥側の耳の線は目立ちにくくなった。大きく振った状態を拡大すると、髪のつなぎ目や耳付近に細い境界が見える。
