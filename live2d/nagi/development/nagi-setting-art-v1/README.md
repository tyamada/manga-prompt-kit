# 瀬尾凪 新規Live2D用設定画 v1

[設定画PNG](nagi-setting-turnaround.png)は、画面左向き・正面・画面右向きの順に並べた胸上の設定画です。正面原画と左右斜めの参考画を参照し、髪型・目の色・制服・胸元のリボンをそろえて新規作画しました。制作には画像生成を使用しました。

斜め向きは見た目で35〜45度を目安にしています。手前の耳、奥側の目の見え幅、鼻先と顎、首と襟の重なりをパーツ分けと変形の基準にします。次工程は正面原画の作成と、髪・顔・耳・首・目・口のレイヤー分けです。
