# 瀬尾凪 顔角度XYZ v5

[編集用CMO3](nagi-angle-xyz-v5.cmo3) · [Viewer用モデル](runtime/) · [音声合成クエリ](narration-v2-accent-preview-3-query.json) · [顔角度XYZ v4](../nagi-angle-xyz-v4/)

左右の横髪を細分化し、角度Xの端で耳との重なりを調整した。前髪の描画順を上げ、左右端では両耳の補足下地を薄くして、下地の縁が髪に出るのを抑えた。

Cubism Viewer 5.3.05で `runtime/nagi-angle-xyz-v5.model3.json` を開き、`AngleNarration` を再生する。音声を付ける場合は、同梱のクエリをVOICEVOX:波音リツ（ノーマル、スタイル9）で合成し、WAVをViewerの音声欄に指定する。音声利用時は「VOICEVOX:波音リツ」を表示する。[波音リツの利用規約](https://www.canon-voice.com/terms/)

音声を割り当てた通し再生で、左右端と斜め向き、視線・まばたき・口パクを目視確認した。耳の補足下地の明るい線を抑えた。大きく振った状態を拡大すると、横髪の根元や耳の脇には細い境界が残る。
