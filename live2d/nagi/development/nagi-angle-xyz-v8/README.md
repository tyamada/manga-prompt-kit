# 瀬尾凪 顔角度XYZ v8

[編集用CMO3](nagi-angle-xyz-v8.cmo3) · [Viewer用モデル](runtime/) · [音声合成クエリ](narration-v2-accent-preview-3-query.json) · [顔角度XYZ v7](../nagi-angle-xyz-v7/)

[波音リツの音声付き通し再生動画](nagi-v8-preview.mp4)（約13秒、VOICEVOX:波音リツ）

角度Xの＋30で、右端のこめかみ付近にある後ろ髪のメッシュ頂点を2点調整し、ハイライトの折れを緩めた。

Cubism Viewer 5.3.05で `runtime/nagi-angle-xyz-v8.model3.json` を開き、`AngleNarration` を再生する。音声を付ける場合は、同梱のクエリをVOICEVOX:波音リツ（ノーマル、スタイル9）で合成し、WAVをViewerの音声欄に指定する。音声利用時は「VOICEVOX:波音リツ」を表示する。[波音リツの利用規約](https://www.canon-voice.com/terms/)

音声を割り当てた通し再生で、左右端と斜め向き、視線・まばたき・口パクを目視確認した。右端ではこめかみ付近のハイライトが下の毛束へなだらかにつながることを確認した。
