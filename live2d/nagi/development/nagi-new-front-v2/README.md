# 瀬尾凪 新規Live2D用 正面原画 v2

[正面原画PNG](nagi-new-front-v2.png) · [パーツ分けPSD](nagi-new-front-v2.psd) · [参照設定画 v2](../nagi-setting-art-v2/)

設定画 v2 の中央の胸上を切り出し、背景を透過しました。PSDは前髪・顔まわりの髪、後ろ髪、顔、左右の耳、首、左右の目、口、胴・衣装の10レイヤーです。耳と目の左右はキャラクター本人から見た向きです。

Cubism Editor 5.3.05に新規モデルとして読み込み、すべてのパーツを表示した状態で前髪と顔・耳、顎と首・襟のつながりを確認しました。前髪・左右の耳・左右の目・口を非表示にして各レイヤーの切り分けも確認しました。正面で見える部分を分けた段階で、隠れている下地は次の作画工程です。
