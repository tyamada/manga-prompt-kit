# 瀬尾凪の左右斜め参考画と補足作画 v1

[正面原画](../../source/nagi-front-winter-indoor-v1.png)を参照して、顔角度を組むための作画を追加しました。

| ファイル | 用途 |
|---|---|
| [画面左向き](view-left.png) | 本人の右向き。手前に本人左の耳が見える。頬の輪郭、鼻先、奥側の目の幅を参照する。 |
| [画面右向き](view-right.png) | 本人の左向き。手前に本人右の耳が見える。前髪を単純反転させず、こめかみと奥側の目の重なりを参照する。 |
| [前髪を上げた補足作画](head-underpaint-reference.png) | 額・こめかみ・両耳・顎の下から襟までのつながりを確認する。 |
| [透過の肌パーツ素材](skin-parts-sheet.png) | 額から顎までの顔の肌、左右の耳、首と肩の付け根を別々に配置した分割用素材。耳の左右は正面から見た配置を基準とする。 |

斜め画は約35度を目安に生成した作画資料です。正面PSDへの位置合わせと色合わせ、レイヤー分割、Cubismでの可動域検証が必要です。顔の変形では手前の頬・耳を見せ、奥の目を狭め、顎と首の境界に重なりを持たせます。

制作には正面原画を画像参照として組み込み画像生成を使用しました。左右の斜め画は正面の胴に顔だけを振り、前髪を上げた資料と透過シートでは隠れる肌を補いました。[利用条件](../../LICENSE.md)
