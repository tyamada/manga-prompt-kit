# 瀬尾凪 新規正面モデルの口リグ v1

[編集用CMO3](nagi-new-front-mouth-rig-v1.cmo3) · [口パク用パーツ分け v1](../nagi-new-front-mouth-parts-v1/)

開閉（ParamMouthOpenY）に0・1、口幅（ParamMouthForm、Editor上の「口 変形」）に−1・0・1のキーを設定しました。閉口線は開きに応じて薄くなり、開口輪郭・口内・舌は同じワープデフォーマで変形します。開閉と口幅の初期値は0です。

Cubism Editor 5.3.05で閉口、半開き、最大開口を切り替え、口幅の両端で開口輪郭と口内・舌の重なりを確認しました。半開きは不透明度の補間で最大開口より口内が淡く見えます。保存し直したCMO3を再読込し、初期状態の閉口と、開閉・口幅を最大にした口形を確認しました。
