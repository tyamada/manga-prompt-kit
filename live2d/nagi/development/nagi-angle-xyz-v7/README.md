# 瀬尾凪 顔角度XYZ v7

[編集用CMO3](nagi-angle-xyz-v7.cmo3) · [Viewer用モデル](runtime/) · [音声合成クエリ](narration-v2-accent-preview-3-query.json) · [顔角度XYZ v6](../nagi-angle-xyz-v6/)

角度Xの−30と＋30で、後ろ髪の外縁とその内側にある頂点を移動し、こめかみの横で輪郭が折れる箇所を調整した。

Cubism Viewer 5.3.05で `runtime/nagi-angle-xyz-v7.model3.json` を開き、`AngleNarration` を再生する。音声を付ける場合は、同梱のクエリをVOICEVOX:波音リツ（ノーマル、スタイル9）で合成し、WAVをViewerの音声欄に指定する。音声利用時は「VOICEVOX:波音リツ」を表示する。[波音リツの利用規約](https://www.canon-voice.com/terms/)

音声を割り当てた通し再生で、左右端と斜め向き、視線・まばたき・口パクを目視確認した。左端では外縁の折れが弱まった。右端ではこめかみ付近の髪のハイライトに小さな折れが残る。
