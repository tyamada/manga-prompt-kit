# 瀬尾凪 顔角度XYZ v11

[編集用CMO3](nagi-angle-xyz-v11.cmo3) · [Viewer用モデル](runtime/) · [音声合成クエリ](narration-v2-accent-preview-3-query.json) · [顔角度XYZ v10](../nagi-angle-xyz-v10/)

角度Xの＋30で、耳脇に重ねた短い髪の補足作画の不透明度を76％から100％に上げ、淡い色差を抑えた。拡大すると補足作画に沿ってわずかな暗い境界が見える。

Cubism Viewer 5.3.05で `runtime/nagi-angle-xyz-v11.model3.json` を開き、`AngleNarration` を再生する。音声を付ける場合は、同梱のクエリをVOICEVOX:波音リツ（ノーマル、スタイル9）で合成し、WAVをViewerの音声欄に指定する。音声利用時は「VOICEVOX:波音リツ」を表示する。[波音リツの利用規約](https://www.canon-voice.com/terms/)

音声を割り当てた通し再生で、左右端と斜め向き、視線・まばたき・口パクを目視確認した。[波音リツの音声付き通し再生動画](nagi-v11-preview.mp4)（約13秒、VOICEVOX:波音リツ）では、右端は約2.1〜2.8秒に表示される。
