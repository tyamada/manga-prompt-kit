# 瀬尾凪 顔角度XYZ v3

[編集用CMO3](nagi-angle-xyz-v3.cmo3) · [Viewer用モデル](runtime/) · [音声合成クエリ](narration-v2-accent-preview-3-query.json) · [顔角度XYZ v2](../nagi-angle-xyz-v2/)

境界を埋める下地を顔の変形に追従させ、首の下地を襟と同じ位置に固定した。左右端の再生で、顎から首に沿っていた長い二重線が解消した。耳の高さでは、胴体と一体の後ろ髪との境界に段差が残る。

Cubism Viewer 5.3.05で `runtime/nagi-angle-xyz-v3.model3.json` を開き、`AngleNarration` を再生する。音声を付ける場合は、同梱クエリをVOICEVOX:波音リツ（ノーマル、スタイル9）で合成し、WAVをViewerの音声欄に指定する。音声利用時は「VOICEVOX:波音リツ」を表示する。[波音リツの利用規約](https://www.canon-voice.com/terms/)

音声を割り当ててモーションを通し再生し、左右の顔角度と視線・まばたき・口パクの組み合わせを目視確認した。
