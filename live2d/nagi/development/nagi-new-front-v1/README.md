# 瀬尾凪 新規Live2D用 正面原画 v1

[正面原画PNG](nagi-new-front-v1.png) · [パーツ分けPSD](nagi-new-front-v1.psd) · [参照設定画](../nagi-setting-art-v1/)

設定画中央の胸上ショットを切り出し、背景を透過した。PSDは前髪・顔まわりの髪、後ろ髪、顔、左右の耳、首、左右の目、口、胴・衣装の10レイヤー。耳と目の左右はキャラクター本人から見た向き。

Cubism Editor 5.3.05に新規モデルとして読み込み、全レイヤー表示で正面の合成を確認した。両耳、両目、口の表示も個別に切り替えて確認した。現在は正面で見えている部分の分割で、表示を外すと下地が抜ける箇所がある。変形前に髪で隠れる肌と目・口の下地を描き足す。
