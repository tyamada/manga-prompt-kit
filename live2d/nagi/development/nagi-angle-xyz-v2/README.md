# 瀬尾凪 顔角度XYZ v2

[編集用CMO3](nagi-angle-xyz-v2.cmo3) · [Viewer用モデル](runtime/) · [音声合成クエリ](narration-v2-accent-preview-3-query.json) · [顔角度XYZ v1](../nagi-angle-xyz-v1/)

[左斜めの参考画](../head-turn-art-v1/view-left.png)と[右斜めの参考画](../head-turn-art-v1/view-right.png)に合わせ、角度Xの左右端と角度Yを組み合わせた位置で、顔のワープを調整した。頬から顎にかけての輪郭が向きに応じて変形し、奥側の目の横幅が狭くなる。

Cubism Viewer 5.3.05で `runtime/nagi-angle-xyz-v2.model3.json` を開き、`AngleNarration` を再生する。音声を付ける場合は、同梱クエリをVOICEVOX:波音リツ（ノーマル、スタイル9）で合成し、WAVをViewerの音声欄に指定する。音声利用時は「VOICEVOX:波音リツ」を表示する。[波音リツの利用規約](https://www.canon-voice.com/terms/)

音声を割り当てた通し再生で、前髪・耳・首の重なりと、視線・まばたき・口パクを目視確認した。左右端では前髪と耳付近に継ぎ目があり、顎から首の境目に二重の輪郭が残る。
