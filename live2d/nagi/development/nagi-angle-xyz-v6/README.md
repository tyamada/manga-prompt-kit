# 瀬尾凪 顔角度XYZ v6

[編集用CMO3](nagi-angle-xyz-v6.cmo3) · [Viewer用モデル](runtime/) · [音声合成クエリ](narration-v2-accent-preview-3-query.json) · [顔角度XYZ v5](../nagi-angle-xyz-v5/)

角度Xの左右端で奥側のこめかみの補足作画を継ぎ目寄りに移動し、不透明度を45％から80％に調整した。正面では補足作画が透明になる。

Cubism Viewer 5.3.05で `runtime/nagi-angle-xyz-v6.model3.json` を開き、`AngleNarration` を再生する。音声を付ける場合は、同梱のクエリをVOICEVOX:波音リツ（ノーマル、スタイル9）で合成し、WAVをViewerの音声欄に指定する。音声利用時は「VOICEVOX:波音リツ」を表示する。[波音リツの利用規約](https://www.canon-voice.com/terms/)

音声を割り当てた通し再生で、左右端と斜め向き、視線・まばたき・口パクを目視確認した。確認モーションの冒頭で角度Xの−30と＋30を保持する。奥側の細い明るい継ぎ目を抑えた。左右端では髪の外縁に段差が残る。
