# 瀬尾凪 顔角度XYZ v12

[編集用CMO3](nagi-angle-xyz-v12.cmo3) · [Viewer用モデル](runtime/) · [音声合成クエリ](narration-v2-accent-preview-3-query.json) · [顔角度XYZ v11](../nagi-angle-xyz-v11/)

角度Xの＋30で、耳脇の補足作画の幅と高さを詰め、位置を毛束に合わせた。不透明度を100％から92％に下げて暗い境界を弱めた。拡大すると短い境目が見える。

Cubism Viewer 5.3.05で `runtime/nagi-angle-xyz-v12.model3.json` を開き、`AngleNarration` を再生する。音声を付ける場合は、同梱のクエリをVOICEVOX:波音リツ（ノーマル、スタイル9）で合成し、WAVをViewerの音声欄に指定する。音声利用時は「VOICEVOX:波音リツ」を表示する。[波音リツの利用規約](https://www.canon-voice.com/terms/)

音声を割り当てた通し再生で、左右端と斜め向き、視線・まばたき・口パクを目視確認した。[波音リツの音声付き通し再生動画](nagi-v12-preview.mp4)（約13秒、VOICEVOX:波音リツ）では、右端は約2.1〜2.8秒に表示される。
