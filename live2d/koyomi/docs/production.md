# v17 制作・確認記録

## 分割と統合

後ろ髪、首と肩、顔の肌、鼻、前髪・横髪へ分割し、既存の眉・目・口とCubismで統合しました。元絵の見えている部分を使い、生成素材は隠れた部分の補完に使用しています。PSDには元の一体原画を非表示の参照レイヤーとして保持しています。実行用モデルではその一体原画を表示せず、分割パーツを使います。

顔のパーツは共通の顔向き・傾きの変形に接続し、首と肩は分離しています。テクスチャは2048×2048の1枚です。前髪・横髪は同一パーツであり、大きな横顔や個々の毛束の物理演算は対象外です。

## 実機確認

Cubism Viewer (for OW) 5.3.04で、この版のMOC3と音声付きモーションを読み込み、実際の画面とシステム音声を同時収録しました。動画はキャラクター領域を切り出し、映像と音声に共通の開始位置6.58秒を適用しています。音声だけ・映像だけをずらす同期補正はしていません。

- 確認動画：720×720、30fps、9.5秒、285フレーム。
- 音声と口の開始推定差：約22ms（音声が先行、測定精度は約1フレーム）。
- 肩4領域の全録画フレーム照合：移動検出0px。
- 3回のまばたき、口の開閉、穏やかな左右・上下向きと傾きを確認。
- 比較画像の時刻はモーション開始を基準とする秒数です。まばたき途中の細い開口も含みます。
- `verification/runtime-check.json` の開始時刻とフレーム数は、切り出す前の全録画に対する測定です。

使用したMacのViewerには、過去の作業で音声開始順序の修正が適用されています。他環境のViewerで同じ開始精度になる保証はありません。音声再生開始後にモーションが合うことを各環境で確認してください。改変Viewerはこの配布物には含みません。

## 公開用の整理

実行用参照をこのフォルダー内の相対パスへ変更しました。MOC3・テクスチャ・CMO3・PSDは内容を保持しています。音声単体WAVは規約確認後に公開対象から外しました。公開用モデル設定からSound参照を外し、音声を追加する手順を同梱しています。手元の制作原本は保持しています。作業場所の絶対パスが映る全画面録画、旧バージョン、作業用スクリプト、アプリ本体は含めていません。

保存確認には `verification/files.json` と `verification/SHA256SUMS` を使います。台帳自身は循環参照を避けるため照合対象から除いています。公開後に内容を更新した際は台帳も更新してください。
