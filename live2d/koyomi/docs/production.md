# v20 制作・確認記録

## 髪揺れ

v19の顔立ち、顔向き・傾き・左右のまばたき・口の6曲線を保持し、前髪・横髪の素材60_Hair_Frontだけを囲うHair_Sway_v20（Warp4）を顔の傾きの子に追加しました。肌・鼻・目・口・首と肩は髪用の変形に含めていません。

髪揺れ前（ParamHairFront）に-1/0/1のキーを作成し、上端を固定、下側ほど少し動く緩やかな変形を設定しています。自己紹介には顔の切り返しに対して遅れと揺り戻しが出る減衰振動を髪用の曲線1本として追加しました。リアルタイムのphysics3設定ではありません。前髪・横髪は一枚の素材を連動させています。毛束の独立分割や大きな風揺れは対象外です。

境界の露出を避けるため再生範囲は約-0.36〜+0.40に抑えています。±1の大きな変形はこの版の利用範囲として推奨しません。CC BY 4.0による改変・利用の追加制限ではなく、見た目を保つための技術上の目安です。

編集用CMO3と実行用MOC3はv20へ更新しました。原画PSD・分割画像はv17から変更していません。元絵の顔立ちと肩固定構造を保持しています。

## 同期・動作確認

- Cubism Viewer (for OW) 5.3.04で、対象モデル1つだけを描画し、画面と実際のシステム音声を同時収録しました。
- 自動目パチ・カーソル追従・呼吸・物理演算をオフにして、保存モーションだけを再生しました。
- 元の自己紹介WAVを変更せず使用。音声に対する口の開始遅れは推定約24ms（測定精度約33ms）。完全な0msの証明ではありません。
- 肩4領域は全フレームで移動0px。顔向き・まばたき・口の動きと髪揺れを同時確認しました。
- 髪だけの確認では、顔の肌と肩の移動は0px、前髪・横髪には約1pxの移動を検出しました。圧縮誤差と1px単位の測定精度を含みます。
- 確認動画：720×720、30fps、9.5秒。共通開始6.25秒で切り出し、映像と音声を別々にずらす同期補正はしていません。
- 検証JSONは切り出し前録画に対する測定です。比較画像の時刻はモーション開始推定が基準です。

Viewerでは対象モデル1つだけを開いて再生してください。旧版の同時描画は遅延の原因になります。未保存の他作業を閉じたり破棄したりしないでください。確認したMacには既存v12のViewer音声開始順序修正があります。今回アプリ本体に追加変更はしていません。他環境・音声機器で同じ開始精度を保証するものではありません。

`verification/history/v19/` は以前の同期調査を保持した履歴です。現在の確認結果は `verification/runtime-check.json` と `verification/hair-isolation-check.json` です。

## 公開範囲

単体WAVと個人パスが映る全画面録画は含めていません。配布モデル設定のSound参照を外し、無音で再生できます。利用者自身の音声生成・追加手順は `audio/README.md` にあります。ソフトウェア・SDK・音声ライブラリ本体も含みません。

独自部分のCC BY 4.0と合成音声の例外は[LICENSE.md](../LICENSE.md)を参照してください。旧v17・v19 Releaseは履歴として保持しています。ファイルの照合には `verification/files.json` と `verification/SHA256SUMS` を使います。台帳自身は循環参照を避けるため照合対象外です。
