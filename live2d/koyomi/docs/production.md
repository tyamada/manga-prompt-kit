# v19 制作・同期確認記録

## バージョンの構成

形状・パーツ境界・編集用CMO3/PSD・MOC3・テクスチャはv17を保持しています。v18では顔向きX/Zを72%、Yを60%へ抑え、まばたきは約80msで閉じて40〜50ms保持し、150〜160msで開くように調整しました。口は開き量を88%に抑え、元のベジェ曲線と閉じるタイミングを保持しています。v19は再生環境と測定手順の改善版です。CMO3/PSDのv17というファイル名は意図したものです。

顔は小さな左右・上下向きと傾きに対応し、肩は顔の変形から分離しています。前髪・横髪は同一パーツです。大きな横顔や毛束の物理演算は対象外です。原画PSDは元の一体原画を非表示の参照レイヤーとして保持しています。

## 原因と対応

Viewerに旧版を含む6モデルのウィンドウが開いていました。保存済みの旧5モデルのウィンドウを閉じて、1モデルだけを描画・再生すると、同じMOC3・モーション・音声で2回とも開始差の推定が約26msまで縮まりました。複数モデルの描画負荷が主な原因と考えられます。CPU使用率の86%→44.4%は参考スナップショットで、厳密な性能試験ではありません。

前回の約92msという測定は録音トラックの開始時刻16.292msを含めておらず、共通時刻基準では約75.7msでした。今回の測定ではトラックの開始時刻も反映しています。モーションや音声に時刻オフセットは追加していません。

再生前に、保存済みの不要なモデル確認ウィンドウを閉じ、対象モデル1つだけで再生してください。未保存の他作業を閉じたり、破棄したりしないでください。録画操作でも対象ウィンドウを明示し、実際に音声・動作が記録されたことを確認しています。

## 検証と動画

- Cubism Viewer (for OW) 5.3.04で画面と実際のシステム音声を同時収録。
- 同じデータの2回の録画で音声に対する口の遅れは推定約26ms。測定精度は約1フレーム（33ms）で、完全な0ms同期を証明するものではありません。
- 肩4領域は全フレーム照合で移動0px。自然な顔向き・3回のまばたき・口の動きを確認。
- 確認動画は720×720・30fps・9.4秒。再録画に共通開始6.54秒を適用して切り出しています。映像と音声を別々にずらす同期補正はしていません。
- 比較画像の時刻はモーション開始の推定時刻を基準としています。検証JSONは切り出し前の録画に対する測定です。
- 確認したMacのViewerでは既存v12の音声開始順序修正が適用されています。今回アプリ本体に追加の改変はしていません。別環境・高負荷・別音声機器で同じ開始精度になる保証はありません。

## 公開用の整理

音声単体WAVと個人パスが映る全画面録画は含みません。配布モデル設定にはSound参照を入れず、無音でも動く構成とし、ローカルで音声を生成・追加する手順を収録しています。公開用モデル設定の参照はフォルダー内の相対パスです。アプリ本体・Core・SDK・音声ライブラリ本体は同梱しません。

独自部分のCC BY 4.0と合成音声の例外は[LICENSE.md](../LICENSE.md)を参照してください。旧v17のReleaseは履歴として保持しています。照合台帳は `verification/files.json` と `verification/SHA256SUMS` です。台帳自身は循環参照を避けるため対象外です。
