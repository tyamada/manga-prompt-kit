## デザイン基準

小坂こよみは高校1年生・149cm・ためし部の発案係。2026-11-09採用の「v10 前向きな表情集」を顔立ちと6表情の基準にします。2026-11-18の衣装更新も確認し、冬の室内服としてコーラルのカーディガン、白長袖ブラウス、えんじ色のリボン、紺プリーツスカート、紺ハイソックス、茶ローファーを基準にします。

赤茶の丸いショートボブ、茶色の瞳、四角いコーラルの髪留めは**本人の右側に1個**。正面では画像左。横顔を単純反転して髪留めを逆にしません。細く明瞭な輪郭線・滑らかな基色・境界の明確なセル影・通常の頭身を維持します。

参照したチャットは「オリジナル4コママンガ制作」「pixivマンガ投稿」。採用画像と最新設定ファイルを実際に確認しています。全身の原画PNGは[こちら](../development/full-body-hands/full-body-front-v1.png)。現在の頭部PSDを全身PSDと呼ばないよう整理しました。

## 進める順序と完了条件

- [x] v21の顔立ち・音声原本・既存の9曲線を保全。

- [x] v23で6表情の試作exp3と30秒シーンを作成し、Viewerの実画面と実音声を同時収録。
- [x] v26で固定領域の下側断片を可動毛束へ戻し、正面再合成一致と境界の重なりを確認。
- [x] v26で6領域に個別メッシュ・変形キーと位相差のあるモーションを設定し、頭部へ接続。
- [x] v27で頭部XYZ入力・6毛束出力の物理演算を追加。Viewerでオン・オフ比較と音声付き動作を確認。配信アプリへの追従確認は別途残作業。
- [x] v25で専用笑顔目・上下左右の視線・6表情の顔の差を実装し、Viewer録画で確認。
- [ ] 独立眉と姿勢を加えた表情演技を仕上げる。
- [ ] 大きな左右向きと上下向き、途中角度、表情＋まばたき＋口開閉の組合せを検証。

完了条件：採用版と同じこよみに見え、髪留めの左右と個数が保たれる。目鼻口の歪み、虹彩の残り、髪や首の穴がない。小さい表示でも6表情を見分けられる。

### 2. 全身・体とリボン

- [ ] 全身PNGから首・胴・左右腕・服・リボン・スカート・脚・靴のPSDを作り、隠れる部分を描く。
- [ ] 顔と全身の倍率・原点を合わせてCubismへ統合する。
- [ ] 顔の変形から肩を分離したまま、呼吸・左右の体揺れ・前のめりを別の親変形へ実装。
- [ ] リボンの控えめな揺れと「気づく→輝く→前のめり」の一連の演技を作る。

完了条件：顔単独時は肩を動かさず、体演技を選んだ時だけ胴と腕が自然に動く。首・肩・服の隙間が出ない。足が滑る全身移動や過大な呼吸を避ける。

完了条件：指と手の左右が正しく、袖や胴の重なりが自然。通常へ戻る際に腕が二重表示されない。
