# v46 横向きの横髪と頬の重なり調整

v45を基に、画面右の横髪の内縁を、横を向くにつれて外へ移動するよう調整しました。45度の位置で頂点の差はなく、既存の髪揺れ設定を保っています。右80度の鼻・顎・首の形状とv42中間向きリグの組み込みは制作中です。

101段階の向きと3通りの開閉で新たな表示面の反転は0件でした。v45との比較で、位置が変わる描画パーツは対象の横髪1点です。モーション・表情・髪の物理設定は同一です。[検証記録](verification/)
