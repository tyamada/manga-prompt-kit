# こよみ v39：右80度の開閉改善・開発版

**45度→80度の自然な移行は未完成です。** 通常配布は[v38](../../README.md)を維持します。

v38のモデルへ、v37の右80度素材から分割した13パーツを追加しました。目は虹彩を薄くする方式から、まぶたとマスクを動かして虹彩を隠す方式へ変更。口は上下の唇・口内・舌を分けて連続変形させ、開きかけで閉じ口の線が残らない構成にしました。顔の傾きにも追従します。

## 編集と実行

`source/koyomi-v39.cmo3` はCubism編集原本、`source/right80/` は右80度用の追加PSD・PNG等、`runtime/koyomi.model3.json` は実行用モデルです。基礎の正面PSDは[通常配布の原画](../../source/koyomi-v38.psd)を参照します。追加素材のPSDだけで全モデル原画を置換しないでください。

`ParamProfileR45=1` を保持し、`ParamProfileR80` を0→1へ動かすと、45度→右80度の試行を確認できます。まばたきは `ParamEyeROpen`、口開閉は `ParamMouthOpenY`。`Right80States` は開閉の低速確認、`Right80Voice` は80度を保持した音声想定、`Right80Turn` は未完成の移行確認です。配布データにWAVとSound参照は含みません。音声再生成と再生設定は[採用音声Iの案内](../../audio/README.md)を参照してください。

## 残る問題

45度と80度は顔・髪の投影が異なり、中間角度で輪郭や目・口が二重に見えます。表示率の調整だけでは自然な接続にならず、55〜70度の形状・隠れ方を作り直す必要があります。右80度専用の6表情は未完成です。既存6表情は正面〜45度側で保持しています。正面〜45度の既存37描画パーツは検証条件下でv38と頂点差1e-6未満。既存の補完4パーツはアトラスの格納密度が65%になっており、完全な画素同一ではありません。

この版を安定版の置き換えや、自然な移行の完成確認として扱わないでください。[照合記録](verification/preservation.json)。
