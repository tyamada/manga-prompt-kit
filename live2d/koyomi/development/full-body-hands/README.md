# 全身・手の演技：素材準備

**全身の原画PNGと右腕の作画資料です。パーツ分け済みPSD、実行用モデル、手のアニメーションではありません。**

[全身原画 v1](full-body-front-v1.png) · [右腕3ポーズの作画候補](hand-pose-guide.png)

右腕の候補は、左から小さなガッツポーズ、ひらめきの指立て、挨拶の手振りです。1枚の白背景の資料で、肩位置・手の大きさ・衣装の色・原画との線幅を調整し、個別に素材化してから取り込みます。肩の接続部・袖と胴の隠れ領域は未検証です。

全身原画を基準に、首・胴・左右腕・リボン左右/結び目・スカート・脚・靴を分け、現在の顔モデルと座標・倍率を統一する必要があります。髪と顔の単独テストでは肩を固定しますが、呼吸・体揺れ・前のめりは別の親変形に分けて実装します。

素材候補には組み込み画像生成ツールを使用。透過の腕試作に外側の光が残ったため採用せず、白背景の3ポーズ資料を保存しました。未完成素材を取り込み可能な完成スプライトとは扱っていません。
