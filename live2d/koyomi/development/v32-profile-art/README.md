## 確認した点と残る工程

髪留めは本人の右側に1個とし、左を向く横顔では遠い側に隠す方針です。耳飾りは追加しません。横顔では遠い側の目を隠し、鼻・唇・顎の輪郭を用意しました。

透明背景PNGですが、輪郭周辺には生成由来の色や白い縁が残っています。正面v31との顔立ち・髪の量・髪留めの形状の一致も最終確認前です。候補をそのままテクスチャに使わないでください。

次は境界と顔立ちを調整し、顔・目・眉・口・耳・髪・首を分割して隠れる部分を描き足します。正面〜45度〜80度の途中形状を設計し、Cubismで左右切替・まばたき・口・視線・6表情を組み合わせて確認します。その後に既存音声同期を保った動画を収録します。既存v31のCMO3・MOC3・PSD・モーション・音声は変更していません。
