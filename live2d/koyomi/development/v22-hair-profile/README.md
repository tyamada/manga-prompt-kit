# v22：毛束・横顔の作業データ

**未完成です。実行用モデルの更新ではありません。**

元の髪を固定領域1枚と可動候補6枚に分割し、7層PSDをCubismの別名CMO3へ追加しました。新規髪フォルダーは非表示、描画順600、親は「顔の傾き_肩固定」です。旧60_Hair_FrontとHair_Sway_v20は保持しています。両方を同時表示すると二重描画になります。

素材の正面再合成は元の髪と色・透明度が一致しています。動かした際の境界露出は未検証です。固定領域に残る毛先断片、根元と隠れ領域を仕上げてから、メッシュ・個別変形・位相差を設定します。

`reference/profile-drawing-draft.png` は左右45度・80度を想定した**作画候補**です。顔立ちと途中角度・肩と首の接続を追加調整する資料で、既存モデルへの実装はまだありません。髪留めは本人の右側1個を基準にし、単純な左右反転で流用しません。

このPSDは頭部の髪だけの追加用で、全身PSDではありません。全体の[制作計画](../../docs/roadmap.md)を参照してください。独自部分は[CC BY 4.0](../../LICENSE.md)。
