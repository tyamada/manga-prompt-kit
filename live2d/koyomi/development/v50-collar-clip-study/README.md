# v50 中間向きの襟元マスク

v49のv42中間向きリグに、首の下側を徐々に透過させる反転マスクを追加しました。衣装側の首へなじませ、首を横切っていた線を目立ちにくくしています。襟の端には短い線が残ります。マスクの編集用素材はPSDで収録しています。

- [顔向きの往復・まばたき・口・6表情の音声付き動画](preview/study-turn-30s.mp4)
- [中間向き固定の音声付き動画](preview/study-voice-30s.mp4)
- [Cubism編集原本](source/koyomi-v50.cmo3)・[実行用モデル](runtime/koyomi.model3.json)
- [マスク素材](source/collar-clip.psd)・[検証記録](verification/)

101段階の向きと3通りの開閉で、既存パーツの形状と設定上の透明度はv49と一致しました。左右の目のマスク、前版の眉、モーションと6表情の設定を保持しています。動画後半の6表情は45度側で確認できます。二重輪郭、右80度の鼻先と顎・首、移植側の6表情の仕上げは制作中です。

音声は **VOICEVOX:春日部つむぎ**（採用音声I）です。Viewerを内蔵スピーカー経由で再生し、映像と音声を同じ時刻で切り出しました。動画側で音声の同期は補正していません。[採用音声Iの利用案内](../../audio/README.md)
