# v45 横向きの鼻先側の輪郭調整

v44を基に、横向きの終点で肌の輪郭を作る4頂点を調整しました。45度とそこから少し進んだ位置までは同じ形を保ち、その先で少しずつ輪郭を変えます。右80度の顔としては鼻先が髪に隠れる部分があり、顎と首の形状調整、v42中間向きリグの統合が残っています。通常配布版はv38です。

通常〜45度・開閉・6表情の頂点位置はv38との差が1e-6未満です。101段階の向きと3通りの開閉で、新たな表示面の反転は0件でした。口・目・表情のモーション、6表情設定、髪の物理設定はv44と同一です。[検証記録](verification/)

確認動画の音声は **VOICEVOX:春日部つむぎ**（採用音声I）です。音声と映像を同時に収録し、同じ位置で切り出しました。公開モデルでの音声の組み合わせ方は[採用音声Iの案内](../../audio/README.md)を参照してください。
