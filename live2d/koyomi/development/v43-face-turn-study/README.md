## 操作と検証範囲

Viewerの `StudyTurn` は最初の約10秒で45度基準と試作の終点を往復し、後半で中間形状の6表情を確認します。`StudyVoice` は中間形状を保持します。既存の名前 `ParamProfileR80` を使っていますが、値1を右80度の完成形として扱わないでください。`ParamProfileR45=1`、`ParamProfileR80Visible=0` を保持して `ParamProfileR80` を0〜1へ動かします。別の顔への表示切り替えはしません。

変更したモーションは顔向き3曲線だけです。目・口・表情・傾き・髪の動作曲線、6表情JSON、髪物理JSON、採用音声Iを保持しました。[動作曲線の照合](verification/motion-preservation.json)。顔向き追加を使わない通常状態・正面〜45度・閉眼・開口・6表情は、v38と頂点差1e-6未満でした。101段階×3通りの開閉で、既存状態に対する表示中の面の反転は0です。[Coreの検証](verification/core-verification.json)。これらの検査を、80度の作画や自然さの合格根拠にはしていません。

原画の再描画・新規画像生成はしていません。基礎PSDは[通常配布](../../source/koyomi-v38.psd)、中間原画と分割素材は[v42](../v42-mid60-rig/README.md)、右80度の素材は[v39](../v39-right80-continuous/README.md)を参照してください。首補正用の `R43_NeckFollow` は恒等変形の補助枠のみで、首の仕上げが完了したことを意味しません。

## 残る作業

v42の顔・目・鼻・耳・髪をv38の基準へ合わせ、45度・中間・80度のパーツ対応と隠れ方を作り直す必要があります。親変形だけの圧縮では正しい横顔にならないため、この試作を完成版へ置き換えません。80度の専用輪郭・遠い目の遮蔽・顎と首の局所形状、全角度での6表情と開閉の再検証が残っています。
