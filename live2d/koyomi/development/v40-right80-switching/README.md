# こよみ v40：まばたき中に切り替える右80度モデル

v39で発生していた、45度側と右80度側が半透明で重なる二重輪郭を、**表示する側を一つに限定する方式**で解消しました。形状を動かすパラメータと表示の切り替えを分離し、閉眼中に切り替えます。**全角度を一続きに変形する連続モーフではありません。** 通常配布の[v38](../../README.md)は維持します。

v38の正面〜45度の顔立ち・採用音声I・既存6表情と、v39で改善した右80度のクリッピングによるまばたき・口の連続開閉を保持しています。

音声：**VOICEVOX:春日部つむぎ**（採用音声I）。音声付き動画では、映像と音声を同じ時間だけ切り出しており、音声単独の時間補正はありません。口内面積と動作曲線を合わせた測定では、音声に対する口の差は約12ms（30fps・面積測定の限界あり）、肩4領域の移動は0pxでした。[同期の測定](verification/video-sync.json)。

## 実行と編集

`runtime/koyomi.model3.json` が実行モデル、`source/koyomi-v40.cmo3` がCubism編集原本です。`source/right80/` に右80度の追加PSD・PNG・SVGを含めています。基礎の正面PSDは[通常配布の原画](../../source/koyomi-v38.psd)を参照してください。

Viewerでは `Right80Turn` の `showcase-r80.motion3.json` を再生すると移行を確認できます。`Right80Voice` は右80度の音声確認、`Right80States` は低速の開閉確認です。動画の後半には既存の6表情が入っています。右80度専用の6表情を新たに完成させた版ではありません。

配布物にWAVとSound参照は含みません。音声を再生成して自分の環境で組み合わせる場合は、[採用音声Iの案内](../../audio/README.md)を参照し、対象モーションへSoundを設定してください。

### 表示切り替えの条件

- `ParamProfileR45=1` と `ParamProfileR80` で右向きの形状を操作します。
- `ParamProfileR80Visible` は **0または1だけ**を設定します。0は従来側、1は右80度側です。0.5などの中間値にすると再び半透明で重なるため、スライダーによる連続補間やフェードに使わないでください。
- 同梱モーションは表示パラメータにステップ補間を使用し、フェードを0に設定しています。独自の実行環境でも、他のモーションを混ぜた後に0/1を直接設定し、切り替えは閉眼中に行ってください。[設定値](runtime/switching-guide.json)。
- 通常側の既定状態は `ParamProfileR80=0, ParamProfileR80Visible=0`、右80度の終点は `ParamProfileR45=1, ParamProfileR80=1, ParamProfileR80Visible=1` です。

## 確認範囲と今後

2本の確認モーションを各120Hz・3,601時点で照合し、従来側と右80度側の顔が同時に表示される状態・両方消える状態は0でした。[照合記録](verification/exclusive-timeline.json)。顔の既存37描画パーツはv38と頂点差1e-6未満、右80度の見える形状はv39と126通りの開閉・傾きで保持を確認。6表情JSON・髪物理JSON・口の動作曲線・採用音声Iも保持しました。[モデル保持の記録](verification/model-preservation.json)。

切り替え時には投影と口幅の変化が残ります。55〜70度の専用形状を作って全角度を連続変形させる作業、右80度専用6表情、全身・手・実際の顔追跡は今後の課題です。v39からの既存4補完パーツのアトラス密度65%は継続しています。
