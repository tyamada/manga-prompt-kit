# こよみLive2Dモデル v20（髪揺れ版）

v19の顔立ちと音声同期を保ち、前髪・横髪に控えめな遅れと揺り戻しを追加しました。旧v17・v19 Releaseは履歴として保持しています。

## ダウンロード

- `koyomi-live2d-v20.zip`：実行用モデル、CMO3・PSD・分割素材、モーション、確認動画、検証記録。展開後は `koyomi/README.md` を参照。
- `SHA256SUMS`：添付ZIPのSHA-256。内部ファイルの照合台帳も同梱。

GitHub自動生成のSource code ZIP/TARはリポジトリ全体です。モデルだけを取得する場合は添付ZIPを選んでください。

## 動作と同期

顔・目・口の6曲線はv19と同一です。前髪・横髪は一枚の素材を連動させた小さな揺れで、髪用パラメータの曲線として収録しています。リアルタイムのphysics3設定や毛束ごとの風揺れは含みません。

実機画面とシステム音声を同時収録し、映像と音声を別々にずらす同期補正はしていません。口の開始遅れは推定約24ms（測定精度約33ms）。肩の固定、顔向き、まばたき、口と髪の動きを確認しました。

Viewerでは対象モデル1つだけを開き、自動目パチ・カーソル追従・呼吸・物理演算をオフにして保存モーションを再生してください。確認Macには既存のViewer音声開始順序修正があります。他環境で同じ同期精度を保証するものではありません。

配布モデルは無音で動きます。`audio/README.md` に音声の生成・追加手順があります。音声付き確認動画、無音版動画、髪だけの確認動画・比較画像を収録しています。編集用CMO3はv20、原画PSDは変更していないv17です。
