# アプリ用公開版PDF 第1〜3話

『ためし部』第1〜3話、14言語・17言語地域区分の51冊を、この制作資料リポジトリへ集約する移行Releaseです。

旧配布先の公開版と同一のPDFで、内容の再生成・改訂はしていません。各PDFの版数、検索用の文字、作者・第三者素材の表示を保持しています。

## ダウンロード

各PDFを個別の添付ファイルから取得できます。pdf-manifest.jsonに言語・地域・話数・タイトル・サイズ・SHA-256・固定URLを、pdf-migration.csvに旧2配布先からの移行対応を記載しています。SHA256SUMSで整合性を確認できます。

## 旧配布先からの移行

このReleaseをPDF最新版の配布先とします。アプリ側のカタログと取得URLの更新は別工程です。旧2Releaseはアプリ移行が終わるまで維持し、その後に廃止日を決めます。この公開だけで旧版アプリの参照先は変わりません。

pixiv投稿用の画像Releaseは含みません。画像の一括配布はpixiv投稿後まで待機します。
