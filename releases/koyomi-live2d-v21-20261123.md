# こよみLive2Dモデル v21（表情追加版）

v20の顔立ち・顔向き・まばたき・口の開閉・髪揺れを保ち、通常・笑顔・驚きの表情を追加しました。

## ダウンロード

- `koyomi-live2d-v21.zip`：実行用モデル、編集用CMO3、原画PSD・分割素材、表情exp3、モーション、確認動画・比較画像、検証記録。
- `SHA256SUMS`：添付ZIPの照合値。内部ファイルの照合台帳も同梱。

展開後は `koyomi/README.md` を参照してください。GitHub自動生成のSource code ZIP/TARはリポジトリ全体です。

自己紹介では表情が自動で切り替わります。手動で使う場合はexpressionsの通常・笑顔・驚きを選択できます。同じ口開きでの表情比較モーション・動画も収録しました。表情は口と眉が中心で、まばたき・口の開閉はそのまま動きます。

最終実機録画では口の開始遅れは推定約24ms（測定精度約33ms）。画面と実際のシステム音声を同時録画し、映像と音声を別々にずらす補正はしていません。Viewerは1モデルだけを開き、自動目パチ・カーソル追従・呼吸・物理演算をオフにして保存モーションを確認してください。確認Macには既存のViewer音声開始順序修正があります。他環境で同じ同期精度を保証するものではありません。

CMO3/MOC3はv21、原画PSDはv17です。大きな横顔・毛束ごとの独立した動きは次版の制作対象で、このReleaseには含みません。旧v17・v19・v20 Releaseは保持しています。
