# 最初の4コマを作る準備

最初は人物2人、場所1か所、小物1つ程度の短い話を作ります。表情、セリフ、持ち物を確認しやすくしてから登場人数を増やします。

## 用意するもの

文章を扱うAIで設定と脚本を考え、参照画像を扱える画像生成・編集手段で作画します。文字配置には、縦書きと文字レイヤーを扱える画像・組版編集環境を使います。PDFを作る場合はフォント埋め込みと検索できる文字の出力も必要です。

この資料集は自動生成アプリではありません。画像生成の利用料や利用枠は各自の環境に依存します。ローカルのPythonなどを使わず手作業で文字を配置する方法でも利用できます。

## 1本を完成させる順序

1. 人物の識別要素を決める。顔、髪、服、小物を確認できる設定画を用意する。
2. セリフと話者を含む4コマ脚本を選ぶ。絵を作る前にオチと読む順序を確認する。
3. 採用する舞台・家具の設定版を決め、各コマのカメラ方向・家具の状態・構図と吹き出しを設計する。人物が後から文字で隠れないようにする。
4. まず1本だけ試作する。最初から全話を量産しない。
5. 文字を組む。画像生成で文字が崩れる場合は別の文字レイヤーを使う。
6. 全4コマを読み、問題を一つずつ修正する。対象外の変化も見る。
7. 採用する版を記録してから投稿用JPEGを書き出す。

## コピーして使う組み合わせ

[人物設定](../prompts/01-character.md) → [脚本](../prompts/03-script.md) → [作画](../prompts/04-color-art.md) → [文字](../prompts/06-lettering.md) → [確認](../prompts/09-review.md)。

『ためし部』を実例として使うなら、[シリーズ設定](../series/tameshibu.md)と、[役割分担の脚本](../examples/02-roles/script.json)を参照してください。人物設定の正確な外見は文字だけで再現せず、実例の画像も添付します。

画像生成の指示内の「添付1」「image1」は自動的にファイルを探す指定ではありません。実際に使用するファイルを選んで、その順番で添付してください。

## 人物設定画がまだない場合

人物設定テンプレートで文章を決めた後、まず正面全身の設定画を作ります。顔・髪・服・靴を切らず、身長比が分かる同じ床の高さで並べ、無地背景にします。名前・プロフィールは後から配置し、人物の見分けと髪留めの左右を確認して採用します。採用した設定画を次の作画へ添付してください。

## 新規作画の文字方針

この資料集で新規制作に勧める基本は「文字なしの作画 → 文字レイヤーでの組版」です。実使用プロンプトには生成時にセリフも描く指示が残っていますが、過去の方法として保存したもので、正確な文字を生成だけで保証する指示ではありません。詳しくは[文字の手順](lettering.md)を参照してください。

## ためし部の部室を使う場合

[部室v2の寸法・4方向の配置](../series/tameshibu/clubroom-20261121/README.md)と[部室参照指示](../series/tameshibu/clubroom-20261121/production-prompt.md)を先に確認します。過去の実例の構図をそのまま現行の舞台設定とみなさず、机の開閉・小物・窓外は選んだ脚本に従います。

採用背景画像は未公開・未収録です。手元に正本がある場合だけ実際に添付し、画像がなければ設定文書による確認と画像による確認を区別します。新しい試作を採用背景と同じものとして扱いません。作業用の参照画像を公開ZIPへ混ぜません。
