# 翻訳と地域別編集

日本語の語句を置き換えるだけでなく、人物の口調、間、オチを保つ翻訳を作ります。東京の高校を舞台とする設定は維持し、翻訳先の学校へ自動的に置き換えません。

## 対訳を固定する

コマ番号、話者、原文、訳文、補足を表で保持します。修正済みの訳文を最終の入力とし、古い脚本から再生成して修正を失わないようにします。作者名の英語表記はKomairo Hiyoriです。

## 組版を言語ごとに調整する

文字数が増えたら、吹き出しの面積と配置を調整します。字数を合わせるためにオチを削ったり、タイトルを横方向に圧縮したりしません。アクセントや声調記号、結合文字を出力で確認します。

## 地域差を扱う

既存制作ではスペインと中南米スペイン語、ブラジルとポルトガル、台湾繁体字と香港用語の繁体字を分けています。香港版は標準書面語で、口語の広東語版ではありません。新しい地域版は、対象読者と違いを記録してから追加します。

## 確認範囲を伝える

AIによる訳文確認と、人による現地校閲は別です。現地の人が確認していなければ、現地校閲済みと表示しません。完成後は訳文の抽出だけでなく、実際の吹き出し、文字の大きさ、検索とコピーも確認します。
