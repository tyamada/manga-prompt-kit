# 文字と吹き出しの制作手順

## 吹き出しのセリフ

脚本を文字データとして保持し、日本語は上から下、列は右から左へ組みます。列を変える位置は意味のまとまりで選びます。句読点、長音、波線、三点リーダーは、縦書きに対応した形と位置を確認します。

フォントは読みやすいゴシック体を基本にし、会話、モノローグ、ナレーションの役割を必要に応じて区別します。縦書き機能のある編集環境でも、フォントによって記号の挙動が異なるため出力で確認します。

同じコマの通常会話は同程度の文字サイズにし、声を張るセリフのみ意図的に大きくします。長い文は文字を縮小する前に、吹き出しを縦長にする、人物を下げる、カメラを引く方法を検討します。

## 発言順と話者

右側の吹き出しが必ず先になるとは限りません。高さ、左右、人物の視線で読み順を設計します。しっぽは話者の近くへ短く付けます。『瀬尾家』「宿題の先生」では、晴の吹き出しを左下、澄を右下へ置きながら、高さを変えて晴が先と伝えるよう修正しています。

## 紙に印刷した文字

吹き出しは読者へ読みやすく置きますが、紙上の印字は物語内で誰が読むかが重要です。[名前の長さ](../examples/03-name/README.md)では凪から読める向きにするため、読者からは逆さに見える印字を使います。

文字列を平面画像として描き、紙の上下縁の形に合わせて変形・合成します。紙の曲面を厳密に再現する3D処理ではなく、作例では画像上の縁から近似しています。向きを変えるときは文字列全体と字形をそろえて回転し、文字の順番だけを逆にしません。

## 最終照合

1. セリフを脚本と一字ずつ比較する。
2. 拡大して字形と重なりを見る。特に細かな漢字と仮名の余分な線を見る。
3. 上から下、右から左の順に実際に読む。
4. 全コマで話者、顔、手、小物が隠れていないか見る。
5. 文字だけの修正でも、人物や背景への変化を確認する。

OCRだけでは細部の字形や会話順の確認はできません。画像と文字データの両方を使います。

## 作画だけを依頼する文面への変更

実使用の原文から新規に作画する場合は、「EXACT dialogue」など画像内へセリフを描く命令を外し、以下へ置き換えます。物語中の紙やラベルも、正確な印字が必要なら後で配置します。

```text
絵だけを作画し、セリフ・タイトル・ラベル文字・権利表示は描かないでください。
各コマの脚本は人物と動作、吹き出し用の空間を決める資料として使います。
顔、手、オチの小物を避けて、指定の話者の近くに必要な文字面積を確保してください。
文字は後で編集可能なレイヤーとして配置します。
```

表紙と権利表示の文字も同じ工程で確定します。完成JPEGでは文字は画像へ統合されますが、再編集用データには文字列とレイヤーを残します。検索できるPDFは、完成JPEGだけから作らず、文字なし作画と文字データを使って組みます。
