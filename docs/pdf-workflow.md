# 検索できる冊子PDFの制作手順

『ためし部』の冊子版はA5縦、右綴じ、8ページです。1ページはカラー表紙、2〜7ページは各2本の縦4コマをモノクロで配置し、8ページはカラー4コマ1本、顔画像入り人物紹介、奥付を収める設計です。合計13本になります。

## 冊子原稿をそろえる

文字なし作画、セリフ、話者、見出し、人物紹介、作者表記を別々に保持します。同じページは右列から左列、各4コマは上から下に読みます。pixivの改稿脚本を使う場合は、元の冊子版とは別の改訂として管理します。

## 文字を画像に焼き込まず配置する

日本語は縦書き、英語は横書きなど、言語に応じて文字を組みます。制作記録にはReportLabとpypdfを使ったPDF生成が含まれますが、この資料集に汎用PDF生成プログラムは収録していません。縦書き・フォント埋め込み・文字対応を扱える組版環境で、以下の仕様を実現します。

文字を表示できてもUnicodeへの対応がなければ検索やコピーが不完全になることがあります。画像の上に見えない文字を置くだけで見た目と内容がずれないよう、出力と抽出文字を照合します。

## PDFの設定

既存制作の目標はPDF 1.5、PageLayoutがTwoPageRight、ViewerPreferencesのDirectionがR2Lです。閲覧アプリによって表示設定の扱いが違うため、右綴じの指定と実際の見開き表示の両方を確認します。

## 確認と配布

- 全8ページを画像として開き、文字切れ、白紙化、吹き出しの重なりを確認する。
- 代表的なセリフとタイトルを検索し、コピーした文字を原文と照合する。
- 埋め込みフォント、アクセント、結合文字、句読点を確認する。
- ファイル名、言語・地域、版、ページ数、バイト数、SHA-256を記録する。
- 公開済みPDFと固定URLを保持し、改訂は別の版として扱う。

移行中の既存PDFは[Viewerの旧固定リリース](https://github.com/tyamada/MihirakiPDFViewer_Android/releases/tag/sample-manga-v2)と[Utilityの旧固定リリース](https://github.com/tyamada/MihirakiPDFUtility_Android/releases/tag/sample-manga-v2)に案内されています。既存51冊の移行ではPDFを再生成せず、公開済みPDFの内容も変更していません。第4話は別の新規固定Releaseで公開しています。

## 既存の公開PDFを新しいReleaseへ移す

アプリ用PDFの最新版配布先は、この制作資料リポジトリのGitHub Releasesに集約します。旧2配布先は将来廃止予定です。[移行計画](../releases/README.md)に、旧ファイル名・サンプルID・ハッシュと新しい配布ファイルの対応をまとめています。

最初の移行は既存の公開版と同一の51冊を使い、PDFを再生成せず、内容の版数も変更しません。配布先とReleaseタグの変更は、作品内容の改訂と区別します。移行前に旧URLを削除せず、新規公開の検証、アプリ側カタログ更新、旧URL利用の終了確認の後に廃止します。廃止日は未定です。
