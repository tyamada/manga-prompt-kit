# 出典と資料の読み方

## 調査した制作チャット

| チャット | この資料集で使った内容 |
|---|---|
| オリジナル4コママンガ制作 | シリーズ設定、冊子の構成、人物追加、翻訳・PDF・版管理 |
| Pixivマンガ投稿 | 11月9日の人物紹介と11月11日の採用稿、生成・修正指示、脚本、文字配置 |
| Qiitaマンガ制作記事を作成 | 画像と文字の分担、修正経緯の説明、記事と作例の時系列 |
| 瀬尾家4コマ漫画の計画を立てる | 三姉妹の設定、通常とギャグ、背景資料、文字と吹き出し、最新稿の指定 |

関連する保存資料と採用記録を照合して編集しています。チャット全体の逐語転載ではありません。公開用資料には個人のメールアドレス、ローカルの絶対パス、ログイン情報、投稿管理用の予約記録を含めていません。

## 原文とテンプレート

`prompts/` のMarkdownは今回編集した汎用テンプレートです。各実例内の `prompts/` は保存された画像生成・編集ツール向け原文で、人がチャットに送った依頼文とは区別します。原文にあるファイル参照やimage1は、その場で添付した画像の役割です。

原文には旧版の条件や実行時の文脈が残ることがあります。本文で最終設定と参照の対応を説明しています。原文が英語でも、日本語のテンプレートから制作を進められます。

## 採用版の根拠

『ためし部』の4コマは採用最新版一覧と各回の採用記録、こよみは採用版v10の記録を使っています。『瀬尾家』は元チャットの最新設定共有文にある「宿題の先生v12」を基準にしています。途中のlayoutファイルに残る未採用という状態だけで、後の採用を取り消しません。

実使用の素材は[素材一覧](../assets-manifest.json)に、収録先・元のファイル名・出典グループ・用途・SHA-256を記録しています。脚本と本文は公開用に整理したもので、保存原文と区別します。

## 配布先の確認日

2026年11月12日にGitHub APIで旧2配布先のsample-manga-v2を確認しました。各51件のPDFが公開され、Utility側はプレリリース区分です。公開済みの状態はAPIの一覧で確認し、PDFの全件再ダウンロードはしていません。移行予定のローカル51冊は、APIに表示されたバイト数・SHA-256と照合しています。

新しい制作資料リポジトリを今後の最新版公開先とし、旧2配布先は将来廃止予定です。確認済みの旧Releaseと、まだ公開していない新Releaseを[配布一覧](../releases/README.md)で分けています。
